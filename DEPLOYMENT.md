# APK Injector Pro - Deployment Guide (Render)

## Overview

This is a Telegram Web App for processing and signing Android APK files. It's built with Node.js, React, and TypeScript, and is ready to deploy on Render.

## Prerequisites

- A Telegram Bot Token (from BotFather)
- A Render account
- Git repository with this code

## Environment Variables

Create a `.env` file or set these variables in Render:

| Variable | Description | Example |
|----------|-------------|---------|
| `TELEGRAM_BOT_TOKEN` | Your Telegram Bot Token | `8737255406:AAEFenbZDgNzz5yX9QLVMdstx2nb6WBftKw` |
| `NODE_ENV` | Environment mode | `production` |
| `PORT` | Server port (Render sets this) | `3000` |
| `DATABASE_URL` | PostgreSQL connection string | `postgresql://user:pass@host/db` |
| `JWT_SECRET` | Secret for JWT tokens | (auto-generated by Manus) |
| `VITE_APP_ID` | App ID | (auto-generated by Manus) |
| `VITE_APP_TITLE` | App title | `APK Injector Pro` |
| `VITE_APP_LOGO` | App logo URL | (optional) |

## Deployment Steps

### 1. Push to GitHub

```bash
git add .
git commit -m "Deploy APK Injector Pro"
git push origin main
```

### 2. Create Render Service

1. Go to [Render Dashboard](https://dashboard.render.com)
2. Click **New +** → **Web Service**
3. Connect your GitHub repository
4. Fill in the details:
   - **Name**: `apk-injector-pro`
   - **Environment**: `Node`
   - **Build Command**: `pnpm install && pnpm run build`
   - **Start Command**: `node dist/index.js`
   - **Plan**: Free (or paid for better performance)

### 3. Set Environment Variables

In Render dashboard:
1. Go to **Environment** tab
2. Add all variables from the table above
3. Make sure `TELEGRAM_BOT_TOKEN` is set correctly

### 4. Deploy

1. Click **Create Web Service**
2. Render will automatically build and deploy
3. Wait for the deployment to complete (usually 2-5 minutes)
4. Your app will be available at: `https://apk-injector-pro.onrender.com`

## Telegram Bot Setup

### 1. Create Bot (if you don't have one)

1. Open Telegram and search for **@BotFather**
2. Send `/newbot`
3. Follow the instructions
4. Copy the token (format: `123456:ABC-DEF...`)

### 2. Set Webhook (Optional)

To receive updates from Telegram:

```bash
curl -X POST https://api.telegram.org/bot{YOUR_TOKEN}/setWebhook \
  -H "Content-Type: application/json" \
  -d '{"url":"https://apk-injector-pro.onrender.com/api/telegram/webhook"}'
```

### 3. Create Web App Link

1. In BotFather, send `/mybots`
2. Select your bot
3. Click **Bot Settings** → **Menu Button**
4. Set the URL to: `https://apk-injector-pro.onrender.com`

Or add a command button in your bot that opens the Web App:

```
/start - Opens the APK Injector
```

## Features

✅ **Auto User ID Detection**: Automatically extracts Telegram user ID
✅ **Token & ID Injection**: Injects both `token.txt` and `id.txt` into APK
✅ **Real-time Progress**: Shows live progress bar during processing
✅ **APK Signing**: Automatically signs with a generated keystore
✅ **Telegram Integration**: Sends processed APK directly to user
✅ **Share Button**: Share APK via Telegram or copy link
✅ **Download**: Direct download of processed APK
✅ **Luxury UI**: Modern dark theme with gradients and animations

## Troubleshooting

### Build Fails

- Check that all dependencies are installed: `pnpm install`
- Verify Node version is 18+
- Check for TypeScript errors: `pnpm run build`

### Telegram Bot Not Responding

- Verify `TELEGRAM_BOT_TOKEN` is correct
- Check bot is not already running elsewhere
- Test token: `curl https://api.telegram.org/bot{TOKEN}/getMe`

### APK Processing Fails

- Ensure `wahm.apk` is in `server/assets/`
- Check that `zipalign` and `apksigner` are available
- Verify disk space for temp files

### Web App Not Loading

- Check that the Render URL is correctly set in Telegram
- Verify HTTPS is being used (not HTTP)
- Check browser console for errors
